# Food-UI

A small full-stack food ordering starter with a React UI and Express API.

## Stack

- `apps/web`: React, Vite, and TypeScript
- `apps/api`: Express and TypeScript
- npm workspaces for one-command local development

## Getting Started

Requirements: Node.js 20+ and npm.

```bash
npm install
npm run dev
```

Open `http://localhost:5173` for the UI. The API runs at `http://localhost:4000`.

Useful endpoints:

- `GET /api/health`
- `GET /api/menu`

Production checks:

```bash
npm run typecheck
npm run build
```
