# Food-UI

A user interface project for food-related applications.

## Description
This project contains UI components and designs for food delivery and restaurant management applications.

## Getting Started

Requirements: Node.js 20+ and npm.

```bash
npm install
npm run dev
```

Open `http://localhost:5173` for the UI.

The EF Core data layer is under `apps/api`. It is intentionally server-free for now; build it with `dotnet build apps/api/FoodUi.Api.csproj` when using a .NET 8 SDK.
